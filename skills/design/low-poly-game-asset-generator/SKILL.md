# 低多边形游戏素材生成器

把参考图中的主体，或用户描述的对象，重绘为可直接投入独立游戏的单一 Low Poly 素材。优先级是：**梗与主体辨识度 > 夸张比例 > 清楚轮廓 > 真实结构**。

## 输入与取舍

- 有参考图时先检查实际图像，提取主体的姿态、主色、表情和最荒诞的辨识特征；忽略背景、文字、水印、UI、人物与其他对象。
- 这是重新绘制，不是普通像素抠图。只有用户明确要求保留原图时才以原像素为主。
- 描述不完整时，保留已知特征，不补充场景、手持物或装饰来“丰富”画面。
- 用户指定对象名称时采用；未指定时可给文件使用简短、恶搞但仍可检索的英文连字符名，例如 `sausage-dog-overclocked.png`。

## 生成契约

输出提示词或图像编辑指令应完整表达下列契约：

| 项目 | 必须满足 |
| --- | --- |
| 主体 | 一个完整主体，居中，正面或轻微 3/4 视角，留透明边距且不裁切 |
| 形状 | 简洁、圆润或块状的玩具比例；强化最有趣的夸张特征 |
| 切面 | 数量适中的大型三角形、四边形或不规则多边形；切面清晰可见而非密集碎面 |
| 颜色 | 高饱和、温暖的游戏配色；每个主材质至少有亮面、中间色、暗面三个色阶；面内近乎纯色 |
| 细节 | 眼睛、嘴、纽扣、孔洞等用少量深色几何块或粗线表现 |
| 光照 | 柔和的正面偏上方插画光；明暗清楚，无真实环境反射或强投影 |
| 背景 | 无场景、无文字、无 UI、无装饰物；交付文件必须具有真实透明 Alpha 背景 |

将这段英文风格基底与具体对象特征组合使用：

`cute low-poly game asset, stylized polygonal illustration, retro arcade game prop, toy-like proportions, chunky geometric facets, large polygon surfaces, clean silhouette, bold simple shapes, playful exaggerated proportions, isolated on transparent background`

每个可直接交给生成器的提示词必须填满这些槽位；可替换方括号内容，但不能省略任何一行：

```text
主体：[对象]；保留并强化：[荒诞特征]。
切面：数量适中的大型、平面化三角形／四边形／不规则多边形，面块清晰可见。
颜色：[主色相]的亮面、[同一主色相]的中间色、[同一主色相]的暗面；三档只改变明度，不以白色胸口或深色五官替代；各切面近乎纯色。
构图：一个完整主体居中，[视角]，四周留透明边距；输出 PNG，背景为真实透明 Alpha（不是白色、灰色、棋盘格或任何颜色背景）。
排除：背景、文字、UI、其他对象、细碎网格、写实纹理、PBR、复杂渐变、摄影式反射。
```

不要用“低多边形”一词替代对切面大小和三档色阶的明确描述。提示词若没有“同一主色相的亮面／中间色／暗面”和“真实透明 Alpha PNG”这两项，就还未完成，不能提交生成。

明确排除：写实毛发或纹理、PBR/金属材质、复杂渐变、摄影式反射、复杂 3D 建模、细碎三角网格、背景与额外对象。

## 荒诞特征的处理

把特征直接转化为轮廓和比例，而不是仅在提示词中提及。例如，腊肠狗要有明显超长身体但保留短腿和头部；叼鱼猫要让鱼和猫嘴都可读；汉堡猫要让面包、夹层与猫脸形成一个主体。真实解剖结构可以让步，缩小后的一眼识别不能让步。

## 交付前检查

1. 在深色与浅色底上检查，确认背景是真透明而不是白底、棋盘格或伪透明预览。
2. 检查主体没有被裁切，边缘没有残留原背景、文字或明显色边。
3. 缩小预览：主体、荒诞特征和主动作仍能被辨识；否则减少细节并加大轮廓与切面。
4. 若生成结果出现多个对象、场景或写实质感，重新生成或编辑该结果，而不是把它称为合格素材。

## 示例

用户说“把叼着鱼的猫做成低多边形素材”时，重点是“一只完整、圆胖的猫咬住一条清晰可见的鱼”，而不是加上鱼摊、餐桌或可爱背景；猫和鱼共同构成唯一主体，背景保持真实透明。
