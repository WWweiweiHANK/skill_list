# Incremental_meowmeowmeow 布局基准

这是用户先前确认的项目基准，不代表当前源代码已验证状态。仅在该项目或明确沿用该布局时读取。当前用户指令与实际新布局优先。

- Godot 4.x，2D 竖屏，参考分辨率 720×1440，主体位于上方约 2/3。
- 顶部常驻栏：720×400。
- 点击对象信息栏：480×78，y=912。
- 底部控制台：720×420，y=1015；控制台按钮 3×2，升级列表 2 列。
- 顶部进度条 y≈80，轻量灰蓝样式；满后触发金币雨。
- 升级按钮整块绿色，不足时灰遮罩；红点需要清晰可辨。
- 背景、BGM、鼠标页签使用缩略图网格，选择后替换。

以上坐标按参考画布理解；不得同时强制所有历史尺寸而造成遮挡。实现前核对锚点、容器、缩放与安全区域。不要在其他设备上直接使用绝对坐标作为响应式布局。
